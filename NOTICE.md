# Notices

## adit-workflow-graphify

`skills/adit-workflow-graphify` is a renamed copy of the graphify skill that ships with the `graphifyy` Python package. On first run it installs that package. The upstream licence has not been checked for this repo. Confirm it allows redistribution before sharing the repo outside the company.

## Third-party plugins

The skills call skills from superpowers, ponytail, ecc and caveman. This repo does not include their code. The installer fetches each one from its own source, and each keeps its own licence.

## Company plugins

`mobileapps-ios` and `mobileapps-foundation` come from `gdncomm/agent-plugins`, a private repository. This repo only refers to them by name.
